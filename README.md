## What it is

EmnexAnime is a hosted HTTP API that gives your app everything it needs to build
an anime **streaming** or **discovery** product — without running any scrapers,
proxies, or resolvers of your own.

You call clean JSON endpoints; we handle the hard parts behind them:

- **Rich metadata** — trending, popular, seasonal and genre discovery, plus full
  anime detail (synopsis, studios, score, relations, recommendations, characters)
  and an airing schedule. Normalized into one consistent shape.
- **Ad‑free streaming** — resolved HLS streams with **multiple servers**, **SUB &
  DUB**, subtitle tracks, intro/outro skip timestamps and preview thumbnails —
  all served through our proxy so they play anywhere, with no extra headers.
- **Clean, stable JSON** — one predictable shape, CORS‑enabled, ready for web and
  mobile. Documented fields are additive — we don't remove or rename them without
  notice.

**Base URL** — `https://api.emnexanime.site` · health check at `/health`.
